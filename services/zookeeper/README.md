# ZooKeeper

ZooKeeper cluster (3 nodes) with ZooNavigator UI.

**Version**: Apache ZooKeeper 3.9.4 | ZooNavigator 1.1.3

## Start

```bash
make up zookeeper
```

## Access

- **Nodes**: `localhost:3270`, `localhost:3271`, `localhost:3272`
- **ZooNavigator**: http://localhost:3273

## Connect

Connection string: `zoo1:2181,zoo2:2181,zoo3:2181`
