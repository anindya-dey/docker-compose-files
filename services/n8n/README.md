# n8n

Workflow automation platform with PostgreSQL backend.

**Version**: n8n 1.120.3 | PostgreSQL 18.1

## Start

```bash
make up n8n
```

## Access

- **Web UI**: http://localhost:3150

## Setup

1. Open http://localhost:5678
2. Create account
3. Start building workflows

## Use Cases

- API integrations
- Data synchronization
- Automated tasks
- Webhooks
