# VaultWarden

Bitwarden-compatible password manager.

**Version**: VaultWarden 1.32.5

## Start

```bash
make up vaultwarden
```

## Access

- **Web UI**: http://localhost:3260

## Setup

1. Open http://localhost:8081
2. Create account
3. Install browser extension or mobile app
4. Server URL: `http://localhost:8081`
